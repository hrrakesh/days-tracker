# Date Difference Calculator 📅

A sleek, responsive web application for calculating precise date differences, including total days, weeks, months, and years between any two dates.

---

## ✨ Features

- **Date Comparison**: Select a target date and a reference date to calculate the exact difference.
- **Quick Today Button**: Easily set the reference date to the current date with one click.
- **Detailed Breakdowns**: View differences broken down into:
  - Total Days
  - Weeks & Remaining Days
  - Months
  - Years
- **Smart Direction Indicators**: Automatically determines if the compare date is in the past, future, or exact same day.
- **Calendar Difference Summary**: Displays human-readable calendar differences (e.g., *2 years 3 months 5 days apart*).
- **Responsive & Modern UI**: Built with a sleek dark theme featuring glassmorphism elements, subtle gradients, and smooth hover effects.
